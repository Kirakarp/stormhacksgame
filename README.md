# Cubed-Sphere Snake

A Three.js prototype for Snake played across a cube-sphere grid, with orbit controls, a 3D orientation minimap, and an HDRI environment.

## Structure

- `main.js`: root application entry point
- `js/assets/`: runtime modules used by the application
- `js/minimap/`: compass and cube-net minimap indicators
- `js/shaders/`: sphere rendering shaders
- `assets/`: material assets such as the HDRI environment
- `index.html`: Vite entry page
